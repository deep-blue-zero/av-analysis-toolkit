# Agent start here

This package prepares and verifies audiovisual evidence. It does not itself certify direct listening, continuous viewing, source authenticity, or literary conclusions.

Before aggregating character performance, check the reuse ledger and use its
measurement-specific baseline contributions. A repeated media occurrence is not
a new acted performance. Partial matches must not merge whole utterances or
bridge identities through composites. Preserve raw occurrence counts for editing
and audience-experience questions. Use `performance-search --reuse-database` to
show the linked provenance. Supplied text and similar delivery do not establish
recording identity; mixed-track similarity alone does not identify a voice.

For Japanese performance questions, use `performance` with selected embedded Japanese
subtitles, a verified subtitle run, or the earlier voice-performance-pipeline's JSON
utterance format. Index verified runs with `performance-index` and locate passages with
`performance-search`. Inspect the candidate timing status and review flags before
using the source time to request frames or a listening clip. Keep model estimates,
on-screen labels, measured mixed-audio contours and actual listening observations separate.

1. Read `AUDIO_ANALYSIS_SPEC_1.2.0_RC1.md`, `docs/AUDIO_QUICKSTART.md`, `docs/METHODS.md`, and `docs/HOW_AGENTS_ANALYZE_MEDIA_WITH_THIS_TOOLKIT.md`.
2. Run `ave doctor`, then `python scripts/self_test.py` when the environment permits.
3. Probe the authorized media and select explicit absolute stream indices when ambiguity exists.
4. For long video, create one `frame-index` run and reuse it with bounded seek extraction.
5. Use `practical` audio storage for ordinary transfer; reserve `forensic` float64 WAV for equality-sensitive work.
6. Admit preexisting LosslessCut clips with `admit-external-clip`; do not assume stream copy merely from a filename or creation tool.
7. Inspect generated images through an actual image interface before claiming visual observations. Treat signal measurements as measurements, not as human-like listening.
8. Record direct text, inspected visual evidence, computed signal evidence, temporal inference, and interpretation as different evidentiary classes.
9. Complete capability, presentation, and review declarations only after real review. Never invent receipts to make a gate pass.
10. Verify runs and archives before transfer. The toolkit performs no uploads and no automatic canonical promotion.

## New audio workflow

Use `audio-track` for time-resolved signal evidence and `render-audio` to render
verified tracks without decoding again. These commands NEVER establish listening.
Default 300-second and 250,000 spectral-row caps bound accidental work. Inspect
warnings, channel layout, coverage, window/tail support and EBU warm-up before use.
For a GBC E11 trial, freeze the actual source and chosen interval; timestamps in
examples are not a selection of the real performance. Do not read the analytical
baseline before locking independent observer outputs in a blinded benchmark.
For continuing development, read `docs/IMPLEMENTATION_HANDOFF.md`.
