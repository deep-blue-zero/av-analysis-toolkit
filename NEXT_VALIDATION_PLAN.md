# Next validation plan

These are proposed validation runs. This implementation task does not execute
the Girls Band Cry or To Be Hero X audits, replay existing hosted observations,
upload media or authorize additional API spending.

Start each run with the owner's analytical question and method, selected source
and streams, exact source hashes, existing claim state and authorized evidence
scope. Keep prior interpretations outside an independent first pass where the
method requires it. Store primary/large derived evidence externally; publish
only generic software fixtures and non-private technical receipts in Git.

## 1. Existing WfM E20 auditory diagnostic: contextual reinspection

Retain the original context-minimized responses and failed probe receipts.
Select one bounded passage containing a lexical discrepancy relevant to a claim.
Use the existing exact audio witness; supply source-bound textual wording,
speaker mapping only where established and the specific discrepancy in Stage 2.
Ask whether the corrected wording changes the delivery/interaction assessment.

Compare atomic observations rather than invalidating a complete response. Map
which inferences depended on the lexical premise, preserve unaffected acoustic
observations unless separately challenged and record a claim delta. Contextual
agreement with supplied wording is not independent transcription validation.
Use a scoped human listening check only for remaining consequential audible
judgments. Any hosted request requires separately confirmed current admission,
media authorization and budget; this plan is not that execution permission.

## 2. GBC E11 concert: holistic performance completion

Preserve the complete `空白とカタルシス` performance as one source object. Map
meaningful musical/formal sections, lyric evidence and relevant intercuts.
Plan coherent `PERFORMANCE_MUSIC` observations where section-level development
is the object; use microclips for local vocal or gesture questions. Bound duration
and cost according to the actual provider's supported limits.

Combine sung realization, arrangement/ensemble changes, body orientation,
gaze/gesture, edit/camera transitions, historical imagery and audience/venue
sound in event packets. Escalate only critical gesture or transition windows.
Generate a claim delta against the prior reading and identify which claims
changed accuracy, mechanism, confidence or scope. Do not infer singer identity
solely from camera focus or synchronization solely from subtitle timing.

## 3. Ordinary TBHX fight

Choose a short exchange with clear action geography. Test initiation, movement
direction, attack/evasion order, contact and reaction order. Start with low-density
temporal reconnaissance, narrow ambiguity, then escalate until adequate or
`OPEN`. Pair relevant impacts/vocal effort with source-bound temporal evidence.
Check that sampling and frame-complete inspections produce appropriately
different confidence rather than automatic confirmation.

## 4. Highly stylized TBHX fight

Choose an exchange containing render/style transitions and uncertain temporal
continuity. Track transition order, object states, geography and damage
accumulation. Test whether the stylistic transition continues the combat event
or follows it as a separate flourish. Preserve alternatives where cutting or
sampling prevents a conclusion. Do not substitute visual attractiveness or a
still composition for temporal evidence.

## 5. TBHX dialogue, action and significant sound

Choose a bounded scene combining dialogue, physical action and music/effects or
meaningful silence. Test textual intent against performed delivery, action order,
soundscape changes and AV timing. Distinguish speech-performance, nonverbal and
soundscape task outcomes. Build one causal-event reading and dependency graph,
then assess its claim delta against the initial reading.

## Receipts and acceptance

For each run retain source/extraction hashes, timing/frame parameters, actual
inspection declarations, raw observer output, Stage-2 context, task capability
scope, scoped human judgments, usage/cost and errors. Record independent versus
shared-context support, local contradictions, downstream recheck state and
remaining `OPEN` questions. Evaluate the analysis by its effect on claims, not
the volume of descriptive output.

Track throughput, extraction/storage cost and bounded observer spend for planning
larger collections. A successful example validates its stated task/scope only.
Do not qualify all Japanese acting, music or action-scene analysis from one
successful passage. Native video-model integration is outside this iteration;
first evaluate targeted auditory observation, adaptive temporal evidence and
holistic reconciliation together.
