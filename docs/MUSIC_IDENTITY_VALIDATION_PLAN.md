# Proposed real-media validation — not executed

This plan does not authorize external lookup, hosted observation, media upload,
catalogue submission or spending. Privately bind actual files by hash/stream;
public receipts use aliases. Inspect sources and credits independently of earlier
interpretations.

| Trial | Evidence | Acceptance criterion |
|---|---|---|
| Twilight Train / No Reason Needed | Two authorized mixed-track intervals; visible song credit; official credit; local overlap/reference candidates | Scoped credits can support composition while non-overlapping excerpts leave recording unresolved; uploader/artist/singer stay distinct. |
| Buddha Bilibili / Beat It family | Original source/tags; explicitly selected intervals; local candidates; optionally authorized fingerprints and related-cover catalogue relations | Shared work forms a proposed family; scoped melody/lyrics can support composition while exact master, performance and arrangement remain independently unresolved until evidenced. |
| Thai shared-TV reaction clip | Frozen text/image interpretation; initially unresolved music route; later scoped identity evidence, new scene packet and claim delta | Strengthen only the relevant music premise, preserving unrelated claims and failed historical observer receipts. |

Record source SHA-256, selected audio stream, source clock/interval, native witness,
transformations, query/response hashes, permissions, actual traffic and paid cost.
Retain alternatives, missing catalogue fields, reference provenance, hashed credit
artifacts, attributed listening declarations and per-level decisions. Explicitly
compare cleaner/contaminated neighboring intervals without automatic submission
expansion. Use legitimate local references and transformed/different-realization
controls; nonmatch cannot prove originality or a different composition.

Optional lookup requires a registered AcoustID application key through an
environment variable and `--allow-external-lookup acoustid`. Normalization needs
its own `--allow-external-lookup musicbrainz`, cache and request ceiling. Without
authorization, preserve local results and unresolved questions. Any hosted
auditory trial retains its existing separate permission, capability and budget
guards; no such trial is part of ordinary music CI.

Each trial produces a new immutable run, portable export/rebinding verification,
scene reconciliation and claim delta. Report exactly what was inspected/tested;
these three clips cannot qualify a backend globally. No remote reference media
is acquired by this plan.
